# 协作注意事项与交接门禁

## 资产与 Git 分离

本仓库是工作本体快照；`02_素材与成片` 是独立媒体包。媒体包必须与本仓库的同一提交版本配套使用。`materials` 只允许作为本地目录联接或复制目录存在，禁止提交。

素材包内包含：15版关键帧、165条原片、15条粗剪、抽帧与边界证据、秋季 OL3D 权威素材。它约 2.65GB，应使用网盘、对象存储、NAS 或团队约定的二进制分发方式同步；不要以 Git 普通对象传输。

## 生产注意事项

- 所有版本隔离。不得为了“补齐”素材或镜头而借用其他版本的 URL、关键帧、原片、提示词、状态文件或成片。
- 续作前检查 `02_运行元数据` 的上传回执、asset bindings、payload/response、技术检查与连续性记录。实际远端 ID、上传 URL、SHA256 只能来自真实回执。
- 生成或修复中发生非 JSON、HTTP 错误、无远端 ID、绑定不一致或媒体验收失败时，记录错误后停在该分支；不得伪造完成或静默重提。
- 参考视频不得充当身份、场景或运动输入。秋季 OL3D 素材与本版已验收关键帧是唯一视觉权威。
- 图像和视频阶段均禁止可读文字、数字、按钮、logo、水印、远景总览、航拍、缩小棋盘、主体过小、水平条纹、scanline、glitch。
- 每镜至多一个清晰玩家输入和一个即时机械反馈；状态变化必须可从上一镜末态追溯。
- 粗剪不得以剪辑掩盖源片缺陷。若源片存在画面损坏、语义漂移或结果不可读，应保留证据、标为不通过并走修复流程。

## 声音与交付边界

- 原片 AAC 为游戏/环境音效；不称为配音、旁白或解说。
- `external_tts_blocked=true`。除非未来单独完成合规的原生 TTS 流程，否则不得补入人声或声称已有配音。
- `final_delivery=false`。本次是完整工作/审片粗剪包；最终商业交付需要单独批准、审片与打包。

## 本地更新方式

1. 先 `git pull --ff-only` 更新本体。
2. 确认 `MATERIALS_MANIFEST.json`（通过脚本生成）与素材包版本相符。
3. 若替换了任何媒体，先将旧素材归档，再生成新的素材哈希清单；不要直接覆盖无法追溯的资产。
4. 修改策划、提示词、审查记录或脚本后，更新本仓库并提交；更新媒体时只分发素材包与新的哈希清单。
