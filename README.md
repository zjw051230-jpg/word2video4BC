# word2video4BC

这是一个面向 Codex 的视频生产工具仓库，同时保存了可协作续作的项目本体快照。仓库只保存文本、结构化元数据、无密钥工具快照和操作规则；所有媒体、权威素材、成片与本机凭据都在 Git 外管理。

## 工具本体

- `install.ps1`、`New-VideoProject.ps1` 与 `scripts/` 提供工作区创建、安装、校验和更新工具。
- `skills/` 保存视频生产、任务日志与 Seedance 相关规范。
- API 密钥只在本机环境配置中保存，不能提交到此仓库。
- 更新仓库时使用 `git pull --ff-only`；不要以清理工作区为由删除项目、快照、日志或生成结果。

## T20260812-144226：秋季 OL3D 小游戏广告（15版）

本次项目快照位于根目录以下位置：

- `01_策划与分镜/ol3d_minigame_ads_15versions`：15版中文策划、长分镜、生产计划及版本隔离清单。
- `02_运行元数据/`：关键帧验收、上传/提交回执、素材绑定、连续性审查、EDL、技术检查和粗剪汇总。
- `03_协作注意事项/`：完整生产门禁、不可绕过的注意事项与项目复盘。
- `04_执行工具快照/`：本批次实际使用的无密钥执行脚本及 SHA256 索引。
- `MATERIALS_MANIFEST.json`：独立素材包的 SHA256 清单；该文件只记录，不携带媒体。

媒体和成片位于本机独立目录 `02_素材与成片`，不属于 Git 仓库。取得同版本素材包后，在仓库目录中运行：

```powershell
.\scripts\Connect-MaterialPack.ps1 -MaterialRoot 'D:\你的路径\02_素材与成片'
.\scripts\Test-Package.ps1
```

`materials` 是本地 junction，始终被 Git 忽略。

## 项目续作门禁

1. V001–V015 的关键帧、提示词、状态、上传回执、远端 ID、原片与粗剪必须严格隔离，禁止跨版混用。
2. 继续视频生产前，必须核验本版关键帧、素材绑定、SHA256、上镜末态与真实上传回执；不得伪造远端 ID 或完成状态。
3. 画面维持近距离斜俯视小游戏操作视角；禁止远景总览、航拍、缩小棋盘、可读文字/数字 HUD、scanline 或 glitch。
4. 粗剪只能使用本版 `original` 内的 R01–R11 原片顺序，并重新保存 EDL、技术检查、边界帧证据与审查结论。
5. `external_tts_blocked=true`：原 AAC 游戏音频不是配音、旁白或解说；`final_delivery=false`，本快照不是最终商业交付。

完整规则见 [协作注意事项](03_协作注意事项/协作注意事项.md) 与 [项目复盘原文](03_协作注意事项/项目复盘原文.md)。
