# 发布边界

CC Switch、API 录入工具、模型路由脚本、Python/ffmpeg 环境检测均归 `env4BC` 所有，本仓库不得重复打包。

任何发布或更新都必须执行“缺什么改什么”，且不得扫描、移动、重命名、覆盖或删除项目素材、成品、交付物、快照、日志、API 私有配置和隐藏任务记录。

公开仓库只包含可复用程序、空白模板、说明文档和通用技能。

工作区实际数据必须分层：`视频本体` 放可复用工具、全局 Skills、索引、运行日志和模板；`项目资源` 放项目、素材、生成结果、交付、快照、私有 API、缓存和项目复盘。根目录旧路径仅作为隐藏兼容映射，不得视为第二份数据，也不得提交到 Git。

明确排除：

- `1.projects` 中的真实项目、剧本、参考图和生成脚本状态；
- `2.submission` 中的交付视频；
- `4.apis` 中的凭据和本机 provider 配置；
- `5.summary` 中可能包含客户或项目细节的历史复盘；
- `6.snapshot` 中的生产快照；
- `task-log.jsonl`、临时目录、缓存、数据库和媒体文件。

安装包只带空目录模板和无密钥的 API 配置程序。发布前必须运行：

```powershell
py -3 -B -X utf8 ".\scripts\validate_package.py" --package-root "."
```
