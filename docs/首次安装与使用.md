# 首次安装与使用

## 1. 准备环境

需要 Windows 10/11、PowerShell 5.1 或更高版本、Python 3.10 或更高版本，以及已安装的 Codex。视频抽帧、转码和拼接还需要 `ffmpeg`。

## 2. 安装（推荐图形界面）

解压安装包后，直接双击：

```text
VideoToolkitSetup.pyw
```

安装器会先扫描：

- Python 是否存在；
- ffmpeg 是否存在；
- Codex 的视频技能是否存在；
- 配音工具的技能和音频程序是否已经存在；
- 目标工作区是否已经初始化。

扫描结果中“已存在，跳过”的项目不会重复安装或覆盖。特别是已经安装配音工具时，视频工具只复用现有 Codex 环境，不安装相关音频程序。

在窗口中选择工作区、填写首次项目名（可留空），点击“安装 / 更新”即可。安装完成后重启 Codex。

## 3. 脚本备用入口

如图形入口无法启动，才使用 PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
& ".\install.ps1" -WorkspaceRoot "D:\视频生成" -ProjectName "我的项目"
```

安装器会创建多项目工作区，把通用技能安装到当前用户的 Codex 技能目录，并执行离线校验。已有同名技能时不会覆盖；确认更新后才使用 `-Force`，旧技能会先备份。

## 4. 创建更多项目

```powershell
& "D:\视频生成\New-VideoProject.ps1" -WorkspaceRoot "D:\视频生成" -ProjectName "项目2"
```

也可以直接告诉 Codex：

```text
我要创建项目，名字叫 项目2。
```

每个项目包含背景参考、动作参考、人物三视图、文本资料、原始任务、提示词包、生成结果和结构化数据目录。

## 5. 配置 API（推荐图形界面）

安装后双击工作区中的：

```text
Seedance API配置.pyw
```

在窗口填写 API Key、Base URL 和模型，点击“保存配置”。API Key 只写入本机 `4.apis\\seedance`，不会出现在聊天、截图或 Git 中。

脚本备用命令：

```powershell
& "D:\视频生成\Configure-SeedanceApi.ps1"
```

程序在终端中隐藏输入 API Key，只把配置写到本机 `4.apis\seedance`。不要在聊天、截图、Git 提交或任务日志中发送密钥。

## 6. 日常操作

向 Codex 说明项目名、目标视频、已有素材、画幅、时长、平台和交付要求。Codex 会先读取任务日志与复盘，再创建任务、保存工作版本、生成提示词，并在获得明确授权后调用付费生成接口。

推荐请求：

```text
在“我的项目”中创建一个新视频任务。先整理素材和镜头方案，写完提示词后停下来让我审核，不要提交付费生成。
```

## 7. 目录说明

- `1.projects`：各项目的当前工作版本。
- `2.submission`：最终交付件。
- `3.skills`：工作区技能副本和项目技能。
- `4.apis`：仅本机使用的 API 配置。
- `5.summary`：全局和项目复盘。
- `6.snapshot`：任务不可变快照。
- `task-log.jsonl`：追加式工作记录。

不要直接编辑 `6.snapshot`。不要把 `4.apis`、项目素材、成片或任务日志提交到公开仓库。
