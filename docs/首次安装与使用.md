# 首次安装与使用

## 安装顺序

1. 先安装独立环境包 `env4BC`，完成 CC Switch、`gpt-5.5 -> deepseek-v4-pro` 精确路由、Seedance API、Python 和 ffmpeg 配置。
2. 再让 Codex 运行本仓库 `install.ps1`，安装视频 skills 和“视频本体 + 项目资源”工作区骨架。
3. 对 Codex 说“我要创建视频项目，名字叫 XXX”，由 Codex 建立项目并初始化七个固定 Chat。

视频包检测 `%LOCALAPPDATA%\env4BC\install-state.json`。未检测到时只警告，不会代替 env4BC 安装或更改环境程序。

## 数据保护

安装和更新只处理清单声明的工具文件，严格执行“缺什么改什么”。首次升级到 v2.2.0 时，安装器只会在同一磁盘内把旧目录原子迁移到 `视频本体` 或 `项目资源`，并创建兼容映射；不复制、不合并、不修改项目内容。之后的更新禁止扫描、整理、迁移、改名、覆盖或删除以下内容：

- `1.projects` 中的项目与素材；
- `2.submission` 中的交付物；
- `4.apis` 中的本机私有配置；
- `5.summary` 中的经验与记录；
- `6.snapshot` 中的历史快照；
- `task-log.jsonl` 与项目隐藏任务状态。

更新公告必须逐项列出实际修改的工具文件，并明确声明上述目录未被修改。不得使用“自动整理全部数据”“迁移所有文件”等模糊表述。

## 日常入口

环境配置和密钥录入使用 env4BC 的本机程序。视频任务、提示词、生成、监控、拉回和交付都通过 Codex 操作。API Key 不得发送到聊天、Git、日志或截图中。
